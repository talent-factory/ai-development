# Übungen: Modul 3: Datenverarbeitung & Dateien

Eine Übung je Lektion, mit Kontrollwerten und Gerüst `start.py` im Ordner `05-beispiele/lektion-N/`. Keine Abgabe am Präsenztag; die Musterlösung `loesung.py` wird nach der Lektion freigegeben.

## 📁 Inhalt

| Übung | Zeit | Thema |
| ----- | ---- | ----- |
| [Übung 1](./ex-01-textdatei.adoc) | 15 Min. | Textdatei auswerten: Wetter Zürich |
| [Übung 2](./ex-02-csv.adoc) | 20 Min. | CSV: Durchschnitt, Filter, Export |
| [Übung 3](./ex-03-json-api.adoc) | 15 Min. | JSON, Wettercode-Dict, API Bern |
| [Übung 4](./ex-04-fehlerbehandlung.adoc) | 13 Min. | Defekte CSV, API-Fehler |

Jede Übung hat einen Pflichtteil und eine freiwillige Erweiterung (Kür).
