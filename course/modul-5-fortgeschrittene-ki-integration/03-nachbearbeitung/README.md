# Nachbearbeitung: Modul 5: Fortgeschrittene KI-Integration

**Aufwand:** ca. 2–3 Stunden  
**Abgabe:** bis Modul 6

Ziel: Dein eigenes Mini-RAG über eigene Texte. Daraus entsteht die Projektidee für das Abschlussprojekt in Modul 6. RAG ist dort *kein* Muss, aber du hast jetzt die Bausteine.

---

## Aufgabe

1. **Texte sammeln:** 5–10 eigene Texte zu einem Thema, das dich interessiert (je 3–10 Sätze, Textdateien oder Markdown). Nimm **nur öffentliche oder unkritische Texte**. Im kostenlosen Gemini-Zugang darf Google Eingaben zur Produktverbesserung verwenden, also keine Firmen- oder Personendaten.
2. **Bauen:** Wende `suche()` und `beantworte()` aus der Lektion auf deine Texte an. Passe nur an, was nötig ist (Ordner, Dateiendung).
3. **Prüfen:** Schreibe fünf Testfragen mit der richtigen Quelle und eine Fallen-Frage, deren Antwort nirgends steht. Bewerte jede Antwort mit dem 3-Punkte-Quellencheck.
4. **Reflektieren:** Fülle den [Reflexionsbogen](./reflexionsbogen.md) aus.

## Abgabe

Ein Ordner mit:

| Datei | Inhalt |
| ----- | ------ |
| `texte/` | deine Texte |
| `rag.py` | dein Code |
| `README.md` | Was macht dein RAG, wie startet man es? |
| `testfragen.md` | fünf Fragen mit Soll-Quelle, Ergebnis, plus die Fallen-Frage |
| `reflexion.md` | der ausgefüllte Reflexionsbogen |

## Bewertung

| Teil | Gewicht |
| ---- | ------- |
| Dokumentenset (passend, sinnvoll gewählt) | 15 % |
| Suche (findet die richtigen Texte) | 25 % |
| Antwort mit Quelle | 30 % |
| Prüfung gegen die Quelle (Testfragen, Fallen-Frage, Quellencheck) | 30 % |

## Ideen für das Abschlussprojekt

Was würdest du gern bauen? Notiere am Ende von `reflexion.md` zwei Sätze: Welches Problem löst es, und braucht es dafür RAG, Tool Use oder etwas anderes?
