# Modul 6: Eigenes Projekt, Abschluss, Fragen

**Dauer:** 1 Tag (4 Lektionen à 50 Minuten)  
**Voraussetzung:** Module 1–5 abgeschlossen.

---

## 🎯 Lernziele

Nach diesem Modul können Sie:

1. ✅ Ein eigenes KI-Projekt von der Idee bis zum lauffähigen Prototyp planen.
2. ✅ Streamlit nutzen, um eine interaktive Web-App zu bauen.
3. ✅ Ein Projekt dokumentieren, testen und deployen (Konzept, keine Produktion).
4. ✅ Zwischen Code- und No-Code-Deployment-Ansätzen abwägen.
5. ✅ Verantwortungsvoll mit KI umgehen: Datenschutz, Fairness, Transparenz.
6. ✅ Das Gelernte reflektieren und gezielt Nachfolgefragen stellen.

---
