# Beispiele: Modul 4: Agentic Coding – KI als Entwicklungspartner

Code-Beispiele und Musterlösungen vom Dozenten.

## Einstieg: Was kopiere ich?

Alle Lektionen arbeiten am selben Projekt, dem Wetterbericht. Jede Lektion beginnt mit dem **Endstand der Vorlektion**, auch wenn du eigene Ergebnisse hast. So starten alle vom gleichen Stand, und wer den Anschluss verloren hat, steigt hier wieder ein.

| Lektion | Startstand: kopiere … | Enthält |
| ------- | --------------------- | ------- |
| 1 | [wetter_bericht/](./wetter_bericht/) | Code und Daten (Startpunkt) |
| 2 | [lektion-1/loesung/](./lektion-1/loesung/) | Code, Daten, `plan.md` |
| 3 | [lektion-2/loesung/](./lektion-2/loesung/) | + `test_wetter_bericht.py`, `vergleiche_staedte` (13 Tests) |
| 4 | [lektion-3/loesung/](./lektion-3/loesung/) | + `bereite_live_wetter_auf`, Wettercodes ergänzt, klare Fehlermeldung (17 Tests) |
| Nachbearbeitung | [lektion-4/loesung/](./lektion-4/loesung/) | + `finde_kaeltesten_tag`, Docstrings, `README.md` (20 Tests) |

> **Erst nach deinem Versuch ansehen:** Die Musterlösung `lektion-N/loesung/` ist das Ergebnis der Lektion N. Schaue sie erst an, wenn du selbst gearbeitet hast.

## Inhalt

- [wetter_bericht/](./wetter_bericht/): lauffähiger Wetterbericht samt Daten, Startpunkt für den ganzen Abend (Stand der Nachbearbeitung von Modul 3)
- [lektion-1/](./lektion-1/) bis [lektion-4/](./lektion-4/): Musterlösungen
- [konserven/](./konserven/): vorbereitete Beispielausgaben für die KI-Momente (Notfall bei Rate-Limit)
- [check_setup.py](./check_setup.py): Setup-Check für die Vorbereitung

Tests laufen in jedem Ordner `lektion-N/loesung/` mit `uv run pytest` (ab Lektion 2).
