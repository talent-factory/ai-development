==== Aufgabenstellung

Schreibe ein Programm `taschenrechner_funktionen.py`, das den Taschenrechner aus Übung 1 **mit Funktionen** neu strukturiert:

1. **Vier Rechenfunktionen** mit Typ-Hinweisen & Docstrings:
   - `add(a: float, b: float) -> float`
   - `sub(a: float, b: float) -> float`
   - `mul(a: float, b: float) -> float`
   - `div(a: float, b: float) -> float | None` (None bei Division durch 0)

2. **Menü-Funktion** `zeige_menue() -> None`

3. **Haupt-Funktion** `main() -> None` mit Schleife:
   - Menü anzeigen
   - Auswahl einlesen (1–5)
   - Bei 1–4: zwei Zahlen einlesen, Funktion aufrufen, Ergebnis zeigen
   - Bei 5: `"Auf Wiedersehen!"` und `break`
   - Ungültige Eingabe abfangen

4. **Einstiegspunkt** `if __name__ == "__main__": main()`

---

==== Beispiel-Menü

```
=== TASCHENRECHNER ===
1. Addieren (+)
2. Subtrahieren (-)
3. Multiplizieren (*)
4. Dividieren (/)
5. Beenden

Wahl: 1
Zahl 1: 10
Zahl 2: 5
Ergebnis: 15.0

Wahl: 5
Auf Wiedersehen!
```

==== Starthilfe (Gerüst)

```python
"""Modularer Taschenrechner mit Funktionen."""


def add(a: float, b: float) -> float:
    """Addiert zwei Zahlen."""
    return a + b


def sub(a: float, b: float) -> float:
    """Subtrahiert b von a."""
    return a - b


def mul(a: float, b: float) -> float:
    """Multipliziert zwei Zahlen."""
    return a * b


def div(a: float, b: float) -> float | None:
    """Dividiert a durch b. Gibt None zurück bei Division durch 0."""
    if b == 0:
        print("Fehler: Division durch 0 nicht erlaubt.")
        return None
    return a / b


def zeige_menue() -> None:
    """Zeigt das Hauptmenü an."""
    print("\n=== TASCHENRECHNER ===")
    print("1. Addieren (+)")
    print("2. Subtrahieren (-)")
    print("3. Multiplizieren (*)")
    print("4. Dividieren (/)")
    print("5. Beenden")


def zahl_einlesen(prompt: str) -> float | None:
    """Liest eine Zahl ein, gibt None bei Fehler."""
    try:
        return float(input(prompt))
    except ValueError:
        print("Ungültige Eingabe – bitte eine Zahl.")
        return None


def main() -> None:
    """Hauptprogramm-Schleife."""
    operationen = {
        "1": ("Addition", add),
        "2": ("Subtraktion", sub),
        "3": ("Multiplikation", mul),
        "4": ("Division", div),
    }
    
    while True:
        zeige_menue()
        wahl = input("Wahl (1-5): ").strip()
        
        if wahl == "5":
            print("Auf Wiedersehen!")
            break
        
        if wahl not in operationen:
            print("Ungültige Wahl – bitte 1 bis 5.")
            continue
        
        name, func = operationen[wahl]
        
        a = zahl_einlesen("Zahl 1: ")
        if a is None:
            continue
        b = zahl_einlesen("Zahl 2: ")
        if b is None:
            continue
        
        ergebnis = func(a, b)
        if ergebnis is not None:
            print(f"Ergebnis ({name}): {ergebnis}")


if __name__ == "__main__":
    main()
```
