## ▶️ Ausführung

```bash
# Im Modul-2-Verzeichnis
cd course/modul-2-python-grundlagen-mit-ki

# Lektion 1
uv run python 05-beispiele/01-variablen_demo.py

# Lektion 2
uv run python 05-beispiele/02-bedingungen_demo.py

# Lektion 3
uv run python 05-beispiele/03-schleifen_demo.py

# Lektion 4
uv run python 05-beispiele/04-funktionen_demo.py
```

> **Hinweis:** Einige Demos enthalten `input()` – im Terminal ausführen, nicht in IDEs ohne stdin-Support.
