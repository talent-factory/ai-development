## 🥪 Live-Demo: Das Sandwich (15 Min)

**Material:** Ein Blatt Papier oder eine andere einfache Aufgabe.

**Ablauf:**

1. Eine Person gibt Anweisungen, eine andere führt sie wörtlich aus.
2. Die Anweisung «Mach mir ein Sandwich» führt zu Missverständnissen.
3. Nach und nach wird die Anweisung präziser: «Nimm das Brot, öffne die Butter, streiche die Butter auf die obere Hälfte …»

**Erkenntnis:**

- Computer verstehen keine Intention, sondern nur exakte Anweisungen.
- Programmieren bedeutet, ein Problem so zu beschreiben, dass eine Maschine es ausführen kann.

---

## 💡 Inhalt: Was ist Programmieren?

Programmieren ist das **Zerlegen eines Problems in kleine, logische Schritte** und das **präzise Formulieren dieser Schritte** in einer Sprache, die ein Computer versteht.

### Der Programmierprozess

1. **Problem verstehen** – Was soll erreicht werden?
2. **Zerlegen** – Welche Teilschritte gibt es?
3. **Logik festlegen** – In welcher Reihenfolge müssen die Schritte passieren?
4. **In Code übersetzen** – Syntax einer Programmiersprache verwenden.
5. **Testen & korrigieren** – Funktioniert es? Wo sind Fehler?
6. **Verbessern** – Lesbarkeit, Wartbarkeit, Effizienz.

### KI verändert den Prozess

- **Klassisch:** Mensch schreibt jeden Schritt selbst.
- **Mit KI:** Mensch beschreibt das Problem, KI schlägt Code vor. Mensch prüft, versteht und passt an.

**Wichtig:** KI beschleunigt das Schreiben, aber nicht das Verstehen. Wer das Problem nicht versteht, kann KI-Ausgaben nicht bewerten.

## 🤖 KI als Partner

- **Copilot / Cursor / OpenCode:** Vorschläge direkt im Editor.
- **ChatGPT / Claude:** Erklärungen, Code-Entwürfe, Fehleranalyse.
- **Der Mensch bleibt verantwortlich:** Richtigkeit, Sicherheit, Ethik.

### Diskussionsfrage

> «Würdest du Code aus einer KI ungeprüft in einem Live-System einsetzen? Warum nicht?»
