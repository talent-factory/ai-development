# Kurskonsolidierung Python & KI
## Proposal für Management-Besprechung

**Datum:** November 2025  
**Autor:** Daniel Senften  
**Status:** Entwurf zur Diskussion

---

## Executive Summary

**Ausgangslage:** Drei separate Python/KI-Kurse mit Überschneidungen  
**Ziel:** Konsolidierung zu zwei aufeinander aufbauenden Kursen  
**Ergebnis:** Klarer Lernpfad, besseres Upselling, reduzierter Wartungsaufwand

| Kennzahl            | Vorher | Nachher        |
|---------------------|--------|----------------|
| Anzahl Kurse        | 3      | 2              |
| Module gesamt       | 15     | 10             |
| Überschneidungen    | ~40%   | 0%             |
| Upselling-Potenzial | Unklar | Klar definiert |

---

## Die zwei neuen Kurse

### Kurs 1: Python Programmierung Basis
**Untertitel:** *Von Null zum selbstständigen Python-Entwickler*

| Aspekt          | Details                                 |
|-----------------|-----------------------------------------|
| **Zielgruppe**  | Absolute Anfänger ohne Vorkenntnisse    |
| **Dauer**       | 5 Tage (1 Tag pro Modul)                |
| **Zeitaufwand** | ~50-65 Stunden inkl. Vor-/Nachbereitung |
| **Abschluss**   | Zertifikat "Python Fundamentals"        |

### Kurs 2: Python & KI-Entwicklung Professional  
**Untertitel:** *KI-gestütztes Programmieren für die Praxis*

| Aspekt.          | Details                                 |
|------------------|-----------------------------------------|
| **Zielgruppe**.  | Absolventen Kurs 1 / Python-Kenntnisse  |
| **Dauer**.       | 5 Tage (5 x 4 Lektionen) pro Modul      |
| **Zeitaufwand**  | ~50-65 Stunden inkl. Vor-/Nachbereitung |
| **Abschluss**    | Zertifikat "AI-Assisted Development"    |
| **Besonderheit** | Code + No-Code/Low-Code kombiniert      |

## No-Code/Low-Code Tools im Detail

### Warum diese Integration?

| Argument                     | Nutzen für Teilnehmer                 |
|------------------------------|---------------------------------------|
| **Schnelles Prototyping**    | Ideen in Minuten validieren           |
| **Breitere Einsetzbarkeit**  | Auch für weniger technische Rollen    |
| **Marktrelevanz**            | Tools werden in Unternehmen eingesetzt|
| **Entscheidungskompetenz**   | Wissen, wann Code, wann No-Code passt |

### Eingesetzte Tools

| Tool         | Kategorie           | Einsatz in Kurs 2              |
|--------------|---------------------|--------------------------------|
| **Flowise**  | AI-Flow-Builder     | Modul 4: RAG visuell bauen     |
| **Langflow** | AI-Flow-Builder     | Modul 4: LangChain-Workflows   |
| **n8n**      | Workflow-Automation | Modul 5: AI-Automatisierung    |
| **Make**     | Workflow-Automation | Modul 5: Enterprise-Integration|

### Code vs. No-Code Entscheidungsmatrix

| Kriterium              | Code besser | No-Code besser |
|------------------------|:-----------:|:--------------:|
| Komplexe Logik         | ✅           | –              |
| Schneller Prototyp     | –           | ✅             |
| Volle Kontrolle        | ✅          | –              |
| Nicht-Entwickler Team  | –           | ✅             |
| Skalierung             | ✅          | –              |
| Einfache Integrationen | –           | ✅             |

## Geschäftliche Vorteile

### Für die Schule

| Vorteil                      | Beschreibung                          |
|------------------------------|---------------------------------------|
| **Klarer Produktportfolio**  | Zwei Kurse, eindeutige Positionierung |
| **Höhere Upselling-Rate**    | Natürlicher Übergang Kurs 1 → 2       |
| **Reduzierter Aufwand**      | Weniger Materialien pflegen           |
| **Differenzierung**          | Einzigartiges Code + No-Code Angebot  |

### Für Teilnehmer

| Vorteil              | Beschreibung                         |
|----------------------|--------------------------------------|
| **Klarer Lernpfad**  | Wissen, wo sie stehen und hinwollen  |
| **Praxisrelevanz**   | Lernen marktrelevante Tools          |
| **Zukunftssicher**   | KI-Kompetenz von Anfang an           |
| **Flexibilität**     | Können Code UND No-Code einsetzen    |
