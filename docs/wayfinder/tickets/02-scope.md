# Ticket 2: Scope – Ein Kurs oder zwei?

**Type:** `wayfinder:grilling`
**Status:** closed

## Question

Das Proposal skizziert zwei aufeinanderaufbaumende Kurse (Python Basis + Python & KI Professional). Deine aktuelle Ausschreibung nennt aber sechs Module in einem Kurs. Soll Wayfinder den einen 6-Modul-Kurs abdecken und der Zwei-Kurs-Split bleibt Proposal-Hintergrund?

## Resolution

Scope auf den einen 6-Modul-Kurs setzen:

- M1: Programmier-Mindset & KI-Tools Setup
- M2: Python-Grundlagen mit KI verstehen
- M3: Datenverarbeitung & Dateien
- M4: Agentic Coding – KI als Entwicklungspartner
- M5: Fortgeschrittene KI-Integration
- M6: Fortgeschrittene KI-Integration | Eigenes Projekt, Abschluss, Fragen

Der Zwei-Kurs-Split aus dem Proposal wird in der Map unter «Out of scope» vermerkt. Er kann später auf der neuen Struktur aufsetzen.
