# Ticket 3: Tiefe des ersten Deliverables

**Type:** `wayfinder:grilling`
**Status:** closed

## Question

Soll Wayfinder zuerst eine Struktur + Inhalts-Mapping liefern (Verzeichnisse, READMEs pro Modul, Zuordnung bestehender Materialien), oder sollen gleich vollständige Lektionen geschrieben werden?

## Resolution

Zuerst Struktur + Mapping.

Das ist der Entscheidungs-Rückenrat: wo landet welches bestehende Kapitel, Übung oder Script. Danach können wir Modul für Modul ausfüllen. Dies reduziert das Risiko, Inhalte an die falsche Stelle zu setzen.
