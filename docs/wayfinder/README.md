## 🚀 Quick Start

### Wenn du eine neue Wayfinder-Session starten willst:

1. Diesen Order öffnen
2. [`WAYFINDER-START.md`](./WAYFINDER-START.md) lesen (3 Min)
3. Für tiefere Sessions zusätzlich [`modul-2-6-research-findings.md`](./modul-2-6-research-findings.md) (10 Min)
4. Ganzen [`modul-2-6-redesign-prompt.md`](./modul-2-6-redesign-prompt.md) kopieren
5. In OpenCode: `/wayfinder start modul-2-6-redesign-prompt.md`

### Wenn du die Map tracken willst:

→ [`kurs-redesign-map.md`](./kurs-redesign-map.md) (GitHub Issues Struktur)
